# Rules 廃止と Bun CLI への移行

ユーザーが指定した「rules をすべて破棄」「スキルのスクリプトは Bun CLI に移し、スキルは呼び出し用にする」を実装します。

## 対象と設計

- 3製品の rules ディレクトリを削除し、`.chezmoiremove` で配置済みのディレクトリも削除します。内容を別の指示へ移植しません。
- 自作6スキルを `dot_agents/skills` に集約します。Claude に必要なリンクだけを配置します。外部プラグインのコードは変更しません。
- `rpt` と `web-fetch` は既存の Bun CLI を継続し、スキルを呼び出し用に短縮します。
- `x-dm` は会話一覧・履歴・検索・送信・返信をサブコマンドとして公開し、Playwright を遅延読み込みします。
- `pr-autofix collect` は既存の収集処理を共有CLIに移します。修正判断はエージェントが行います。
- `agent-pr` は context / commit / publish を提供します。git と gh は配列引数で呼び、publish は既存PR更新またはDraft作成を行います。文面はファイル入力です。
- `handoff write` はJSONのブリーフを受け、Git情報を補完して既存のhandoff保存先へ新規ファイルを書きます。
- 各CLIは help、引数検証、非ゼロ終了コードを提供します。

## 実装と検証

- [x] rules と参照を削除し、既存のルール存在テストを新しい配置契約へ更新する
- [x] x-dm を Bun CLI に移し、help・入力検証・操作分岐を外部送信なしで検証する
- [x] pr-autofix collect を Bun CLI に移し、既存の収集テストを維持する
- [x] agent-pr を実装し、一時Gitリポジトリと偽のghで差分収集・コミット・Draft作成/更新・失敗伝播を検証する
- [x] handoff を実装し、一時Gitリポジトリでメタデータ・本文・上書き回避を検証する
- [x] スキルを共通化し、旧スクリプト・旧配置・参照切れを除去する
- [x] chezmoi の一時配置でリンク・CLI起動・削除対象を検証する
- [x] 関連テストを実行し、差分レビュー後に対象を絞って chezmoi apply する
- [ ] コミット・push・Draft PR 作成まで進める

レビューで PR の操作先、明示した削除ファイルのコミット、X の宛先照合と送信結果の扱いを修正しました。X への実アクセス・送信は行わず、CLI とブラウザ操作のテストダブルで検証します。
