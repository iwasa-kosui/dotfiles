# エージェント runtime 共通ポリシー

## Ship 境界

実装、設定変更、バグ修正のタスクは、必要な検証を終えた後に **Draft PR まで** ship してよい。Draft PR はレビュー可能な下書きであり、ユーザーの明示的な承認を置き換えない。

**Ready 化**、merge、force-push、保護ブランチへの直接変更は、いずれもユーザーからの明示的な承認を受けるまで行わない。

## Ship しないタスク

質問への回答、調査、コードレビュー、設計相談、または変更を伴わない状況確認では ship しない。ユーザーがコミット、push、または PR 作成を止めるよう指定した場合も ship しない。
