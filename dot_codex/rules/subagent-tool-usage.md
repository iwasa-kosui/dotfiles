# サブエージェントでのツール使用制限

サブエージェントを含む全てのコンテキストで、以下のルールを厳守する。

## 原則: 専用ツールを優先し、シェルのパイプラインを避ける

ファイルの読み取り・検索・加工には Codex のファイル・検索ツールを使う。
`cat file | python3 -c "..."` や `cat file | jq` のようなパイプラインは許可プロンプトを発生させるため禁止。

### 具体的な禁止パターンと代替手段

| 禁止 | 代替 |
|---|---|
| `cat file \| python3 -c "..."` | ファイル読み取りツールでファイルを読み、内容をコンテキスト内で解析する |
| `cat file \| jq '.key'` | ファイル読み取りツールでファイルを読み、必要な値を抽出する |
| `cat file \| grep pattern` | 検索ツールを使う |
| `find . -name "*.ts"` | ファイル検索ツールを使う |
| `cat file \| sed ...` | ファイル読み取り・編集ツールを使う |
| `cat file \| wc -l` | ファイル読み取りツールで読み、行数を数える |

### シェルを使ってよいケース

- git, gh, npm, bun 等のCLIツール実行
- ファイルの読み取りを伴わない単純なコマンド（`ls`, `pwd` 等）
- 専用ツールでは不可能な処理（プロセス管理、ネットワーク操作等）

### JSON/構造化データの処理

ファイル内のJSONを解析する場合、ファイル読み取りツールで読んでからコンテキスト内で必要な情報を抽出する。`python3 -c` や `jq` にパイプする必要はない。
