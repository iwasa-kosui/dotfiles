# Minutes

`minutes --help` で使い方を確認します。

## 検索

`minutes search "<問い>"` を実行します。会議名や日付で絞れる場合は `--since` / `--until` / `--kind` を付けます。

検索結果に出た `<パス>:<行>` の前後を、エージェントが読んでから答えます。答えには会議名・日付・時刻を添えます。1回の検索で見つからない場合は、問いを言い換えてもう一度検索します。

## 取り込み

ユーザーから zip やフォルダのパスを渡されたら、`minutes ingest <path>...` を実行します。`--delete-source` は、元ファイルを消してよいとユーザーが言ったときだけ付けます。

## 誤字辞書

`~/minutes/typos.tsv` に、`誤り<TAB>正しい表記` の形式で1行ずつ書きます。書き終えたら `minutes retypo` を実行し、全件に辞書を当て直します。辞書に足す語は、ユーザーの了承を得てから足します。

## ollama に接続できない場合

ollama の起動と `ollama pull bge-m3` の実行を、ユーザーに案内します。

## 取り扱い上の注意

議事録には 1on1 や顧客との打ち合わせが含まれます。検索結果の本文を、外部サービス（Web 検索、Slack、GitHub など）に送りません。
